Scrub to a clean pre-snap frame
  1. Scrub to a clean pre-snap frame (both teams lined up); Mark it as the snap.
  2. Click where a yard line meets a sideline on the field.
  3. Add 4+ points: two yard lines ≥15 yd apart, each at both near & far sidelines.
  4. For each point set Yard (the yard line, 0–100) and Across (0 = near sideline, 53.33 = far).
  5. Save, then Run analysis.
